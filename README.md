# Venneplan
Mobil app til at styre planer med venner.

Appen giver dig mulighed for at chatte, oprette og deltage i events med alle dine venner.
Ved oprettelse af et event, ville du altid kunne se information som tid og sted, så du aldrig bliver i tvivl igen.
Hold øje med dine top venner, ved at optjene points for hvert event eller chat du har sendt.
